The library grows

A poster, a title, a hosted URL.

Keep large video out of Git. A recording is a 780×1688 poster in assets/demos/ plus a hosted video URL; the row above is the only place it needs to be listed.

  • Record at 390×844, then capture the poster at 2× — 780×1688.
  • Host the file on Cloudflare Stream, Mux, or R2; link the playback URL.
  • List the flow, one line of context, length, and the screen it belongs to.
  • Keep the same row shape as the library grows — no new layout per demo.
