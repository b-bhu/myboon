Rulebook

One system, every screen.

Background ladder instead of shadows. Hairline borders. Monospace for anything numeric. Gold marks action and the active tab — it never becomes a theme.

Component catalog18 sections. Every approved rule and component, rendered live, with the screens embedded. DESIGN.mdThe written spec. When the catalog and the spec disagree, the spec wins.
Rule 01

Gold is an accent, not a background. The one exception is the Wallet header, where gold floods the top of the screen.
