# episodes/

```

  voice/        # per-line voice files from scripts/voice.ts (not committed)
  takes/        # generated ON CAM host takes (not committed)
  visuals/      # screenshots/charts for OVER VISUAL rows
  ticker.json   # that day's price ticker data (symbol, price, daily % change)
```
